Fully Open-Source Grav Projects

[Grav](https://getgrav.org) (15.7k ★s) is a flat-file CMS that stores content as plain Markdown files instead of a database, edited through a browser-based Admin panel, and runs on any standard web host with PHP 8.3+. These four skeletons – fully open-source, built on the newly released Grav 2 – cover course hubs, multi-course sites, and open publishing spaces.

Each shares the same portable Markdown files and optional Git Sync – Course Hub, MultiCourse Hub, and Publishing Space also support LMS-ready embedding for platforms like Canvas and Moodle.

Which one do I need?

    - **Running a single course?** Grav Open Course Hub. - **Running several courses from one site?** Grav Open MultiCourse Hub. - **Publishing collaborative writing, not course content?** Grav Open Publishing Space. - **Publishing documentation, not courses?** Grav Learn2 with Git Sync.

Also Free: Git Page Link Plugin

The [Git Page Link Plugin](https://github.com/hibbitts-design/grav-plugin-git-page-link) works with any Grav theme – not just these four skeletons. It adds an "Edit this Page" link back to the Markdown source, for open authoring and community contribution.
