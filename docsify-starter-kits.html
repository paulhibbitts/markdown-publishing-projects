Docsify Starter Kits

Static Site

The Docsify Starter Kits are a family of free, open-source templates that transform Docsify into ready-to-run open course sites, multi-course hubs, and publishing spaces – built on Markdown files hosted on GitHub or Codeberg, with no web server setup required and the flexibility to host anywhere, including your own custom domain.

No build process, complete platform independence, and LMS-ready embedding out of the box – Docsify generates your site live from Markdown files, so there’s nothing to compile and no pipeline to maintain.

Jump to: Choose Your Kit · Get Started Now

How do These Compare to Docsify‑This?

Comfortable with GitHub? The Starter Kits are a natural fit – your repository is the site, with no hosting costs.

Want your own URL and full CSS control? The Starter Kits offer both, and the freedom to host wherever you choose.

Not sure yet? Start with Docsify‑This and move that same content to a Starter Kit later – no rework required.

Built for Publishing and Sharing

A complete, ready-to-run site from your Markdown files – yours to host, customize, and share wherever you choose.

  • Customizable – adjust fonts, colors, and behavior with CSS
  • Edit in place – update your Markdown source files directly on GitHub, no re-publishing needed
  • Live preview, no build step – commit to GitHub and changes go live shortly after, or work locally and see changes instantly
  • Optional "Edit this Page" link – for easy community contribution and open authoring
  • LMS-ready embedding – URL parameters toggle the Table of Contents, navbar, and page-only display
  • Open by default – your content lives in your own GitHub repository, portable and version-controlled throughout

What’s Available

  • Open Course, MultiCourse, and Open Publishing site templates
  • LMS-ready embedding with ?embedded=true and related URL parameters
  • Built-in CSS classes for buttons, cards, accordions, badges, image layouts, and more
  • Optional page Table of Contents, footer, navbar, and "Edit this Page" link
  • Guides and documentation in each kit’s README
