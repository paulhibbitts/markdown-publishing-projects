Cost-Free Grav Projects

Full CMS

Grav (15.7k ★s) is a flat-file CMS that stores content as plain Markdown files instead of a database, edited through a browser-based Admin panel, and runs on any standard web host with PHP 8.3+. These four skeletons – fully open-source, built on the newly released Grav 2 – cover course hubs, multi-course sites, and open publishing spaces, well suited to OER and other open educational content.

Each shares the same portable Markdown files and optional Git Sync – Course Hub, MultiCourse Hub, and Publishing Space also support LMS-ready embedding for platforms like Canvas and Moodle.

Also Free: Git Page Link Plugin

The Git Page Link Plugin works with most Grav themes – not just these four skeletons. It adds an "Edit this Page" link back to the Markdown source, for open authoring and community contribution.

Looking for the Premium Option?

Grav Helios Course Hub and Grav Helios Open Reader share the same Markdown-and-Git-Sync foundation as these four skeletons, with a Grav Premium Helios theme, context-aware search, and a versioning system – at the cost of a one-time Premium Helios theme license. Building a companion site for one or more courses? See Grav Helios Course Hub. Publishing a structured open textbook or guide? See Grav Helios Open Reader.
