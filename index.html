One idea, three levels of capability

Start with Docsify-This to publish instantly, no setup required. Move to a Docsify Starter Kit when you want your own domain or custom CSS. Graduate to Grav Helios – Course Hub or Open Reader, depending on what you're publishing – when you want a full CMS with an admin panel. Your content stays as plain Markdown files you control, portable across every option below.

Free & Open Source

A Cost-Free Way to Use Grav CMS

Course Hub and Open Reader both build on the paid Grav Premium Helios theme – a purchase that directly funds continued development of the open-source Grav CMS itself.

If you're looking for a completely free way to use Grav instead, these skeletons share the same Markdown-and-Git-Sync workflow and browser-based admin panel. They come with example content already in place, so you're editing rather than starting from a blank site. All four are built on free, open-source themes and the newly released Grav 2, which needs a web host running PHP 8.3+. There's also one more free plugin that pairs with any Grav site, skeleton or not. The two course hub skeletons below also have an upgrade path into the paid Course Hub above, if you outgrow them:

  • Open Course Hub– a single-course hub with weekly module navigation
  • Open MultiCourse Hub– the same, plus a top-level course-selection layer for managing several courses
  • Open Publishing Space– collaborative Markdown publishing on the free Quark theme
  • Learn2 with Git Sync– documentation sites on the free Learn2 theme, with search and RSS/Atom feeds
  • Git Page Link Plugin– adds an "Edit this Page" / "View Source" link back to the Markdown source, on most Grav themes
