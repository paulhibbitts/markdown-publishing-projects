One idea, three levels of capability

Start with Docsify-This to publish instantly, no repo required. Move to a Starter Kit when you want your own domain or custom CSS. Graduate to Grav Helios – Course Hub or Open Reader, depending on what you're publishing – when you want a full CMS with an admin panel, still just Markdown underneath.

Free & Open Source

A Cost-Free Way to Use Grav CMS

Course Hub and Open Reader both build on the paid [Grav Premium Helios theme](https://getgrav.org/premium/helios) – a purchase that directly funds continued development of the open-source Grav CMS itself. If you're looking for a completely free way to use Grav instead, these skeletons share the same Markdown-and-Git-Sync workflow and browser-based admin panel, all built on free, open-source themes and the newly released Grav 2 – plus one more free plugin that pairs with any Grav site, skeleton or not:

  • Open Course Hub– a single-course hub with weekly module navigation
  • Open MultiCourse Hub– the same, plus a top-level course-selection layer for managing several courses
  • Open Publishing Space– collaborative Markdown publishing on the free Quark theme
  • Learn2 with Git Sync– documentation sites on the free Learn2 theme, with search and RSS/Atom feeds
  • Git Page Link Plugin– adds an "Edit this Page" / "View Source" link back to the Markdown source, on any Grav theme
